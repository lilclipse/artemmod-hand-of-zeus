# ⚡ Hand of Zeus

Minecraft Fabric мод про Руку Зевса, карму и странные события, которые постепенно превращают обычный мир в хоррор.

> **Версия:** 1.1.0  
> **Minecraft:** 1.21.10  
> **Loader:** Fabric

## 🗿 Что это за мод?

Ты получаешь **Руку Зевса** и возможность управлять молниями. Но сила имеет последствия.

Чем больше ты пользуешься Рукой и чем больше добрых существ убиваешь, тем выше становится **карма**. При высокой карме мир начинает реагировать на игрока сам.

И главное: иногда кажется, что кто-то наблюдает за тобой.

## ⚡ Рука Зевса

Основной предмет мода.

- вызывает молнию;
- имеет собственную механику использования и кулдаун;
- использование повышает карму;
- может запускать случайные события;
- доступна с начала игры.

## 👁️ Зевс-наблюдатель

Редкий NPC, который может появиться во время хоррор-событий.

- наблюдает за игроком;
- появляется неожиданно;
- при появлении накладывает **тьму**;
- если игрок замечает его, Зевс исчезает с частицами;
- после исчезновения появляется случайное жуткое сообщение.

## ☠️ Карма

Карма является скрытой системой прогрессии хоррора.

### Карма увеличивается за:

- использование Руки Зевса;
- убийство животных;
- убийство жителей;
- убийство железных и снежных големов.

Чем выше карма, тем больше вероятность мировых событий.

## 🌑 Мировые события

Некоторые события не требуют использования Руки.

При накоплении кармы могут происходить:

- странные сообщения в чате;
- неожиданные звуки;
- тьма;
- появление Зевса;
- другие атмосферные события.

Высокая карма делает мир всё менее предсказуемым.

## 🧪 Эликсир забвения

Эликсир позволяет избавиться от накопленной кармы.

Но цена есть всегда.

После использования игрок получает негативные эффекты и слышит реакцию бога.

**Крафт:**

`Молоко + гнилая плоть`

## 📖 Книга грома

Специальная книга-руководство, которая помогает разобраться с модом без раскрытия всех его секретов.

**Крафт:**

`Книга + гнилая плоть`

Книга также может стать частью некоторых событий при высокой карме.

## 🎒 Начало игры

При первом появлении в мире игрок получает:

- 1× Рука Зевса;
- 1× Книга грома.

## 🎯 Идея мода

Мод построен вокруг простой идеи:

**получить силу легко. Узнать её цену сложнее.**

Используй Руку сколько хочешь. Только помни, что мир всё замечает.

## 🛠️ Сборка

Проект использует **Gradle** и **Fabric Loom**.

Для сборки:

```powershell
gradle clean build
```

Готовый `.jar` находится в:

```text
build/libs/
```

## 📌 Статус

Проект находится в активной разработке. Механики и баланс могут изменяться.
